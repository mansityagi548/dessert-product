# 🍰 Dessert Cart

A dessert ordering app where users can add items to cart, adjust quantities, and confirm orders.

[View Live]()

## 📸 Preview
![Cart With Items](./preview/preview%20.png)


## ✨ Features
- Add/remove desserts to cart
- Increment & decrement quantities
- Order total calculated dynamically
- Cart persists on refresh (localStorage)
- Order confirmation modal
- Empty cart state

## 🛠️ Built With
- HTML
- CSS
- Vanilla JavaScript (ES6 Modules)

## 📁 Project Structure
scripts/
  ├── script.js      - event listeners & main logic
  ├── renderHtml.js  - rendering functions
  ├── cart.js        - cart state & localStorage
  └── product.js     - dessert data
